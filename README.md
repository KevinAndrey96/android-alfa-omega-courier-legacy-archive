## 📌 Historical Overview

This repository preserves the historical native Android application for urban couriers originally developed for the Alfa and Omega Logistics Fleet Dispatch Platform. It featured live GPS route tracking, digital signatures, and camera photo delivery confirmation.

All components, database schemas, and workflows have been merged and modernized into the primary repository: **[android-logistics-fleet-dispatch-platform](https://github.com/KevinAndrey96/android-logistics-fleet-dispatch-platform)**.
